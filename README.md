# 📘 Estudos de TypeScript

Repositório dedicado à resolução de exercícios, desafios práticos e anotações técnicas desenvolvidas durante os estudos de **TypeScript**.

## 🎓 Curso de Referência

* **Playlist no YouTube:** [Curso de TypeScript — Playlist Completa](https://www.youtube.com/playlist?list=PLb2HQ45KP0Wsk-p_0c6ImqBAEFEY-LU9H)

## 📂 Estrutura do Projeto

Os códigos estão organizados por módulos dentro do diretório `src/`:

* **`modulo-01/`**: Fundamentos, configuração do compilador (`tsconfig.json`) e tipagem básica.
* **`modulo-02/`**: Funções tipadas, tuplas, `interfaces`, `types`, *Type Narrowing* e *Switch* exaustivo com `never`.


## 🎯 Conceitos Praticados

* Tipagem estática e inferência de tipos
* `interface` vs. `type` (Union Types, Intersection Types e imutabilidade com `readonly`)
* Desestruturação de tuplas e arrays tipados
* Manipulação segura de strings e números (Template Strings, `.trim()`, `.toFixed()`)
* *Type Narrowing* e *Exhaustiveness Checking* com `never`
* Classes, modificadores de acesso e orientação a objetos
* *Generics* e *Utility Types*
